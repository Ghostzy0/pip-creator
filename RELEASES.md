# Releases

This repository is an early source alpha; no versioned public binary or notarized package is available. The four local ad-hoc-signed app bundles for reviewed development source `fa862802b746fa687c6a3cd71c56d791e8b13c21` passed strict signature and ZIP integrity checks; hashes remain in the private development workspace and are not distributed here. The public clean clone requires fresh build and restore verification.

A public binary release requires a clean-clone test, fresh package built from the public repository, native walkthrough, accessibility and runtime review, provenance/license/security checks, and clear migration notes. Do not install an unsigned or unnotarized package as if it were a verified general release.
