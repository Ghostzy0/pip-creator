# Releases

This repository is an early source alpha; no versioned public binary or notarized package is available. Four local ad-hoc-signed app bundles were built from public candidate commit `0af08e617d86082718bf7abbb6e54f7d14060673`; strict signature and ZIP integrity checks passed. The build receipts are local development evidence, not a distributed release. A fresh clone from GitHub still needs restore and build verification.

A public binary release requires a clean-clone test, fresh package built from the public repository, native walkthrough, accessibility and runtime review, provenance/license/security checks, and clear migration notes. Do not install an unsigned or unnotarized package as if it were a verified general release.
