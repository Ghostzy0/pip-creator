# Releases

This repository is an early source alpha; no versioned public binary or notarized package is available. Four local ad-hoc-signed app bundles exist for source commit `39e06348f5063442f1dec288766d786e1268e547`; their local SHA-256 receipt is retained in the development workspace, not distributed as a binary release.

A public release requires a clean-clone test, fresh package built from the public repository, native walkthrough, accessibility and runtime review, provenance/license/security checks, and clear migration notes. Do not install an unsigned or unnotarized package as if it were a verified general release.
